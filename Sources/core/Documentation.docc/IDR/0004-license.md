# IDR#0004 License

2026-02-01

## Context and Problem Statement
The License is important for the legacy framework.

## Decision

**Chosen option:**

* Provided under permissive license, so You are bound by trust, not by restrictions and requirements.
* Provided under triple license
  * **0BSD**, because it is the better *public domain*. You can do what you want and relicense under all other license from MIT to AGPL - all is allowed.
  * **Apache 2.0**, because it is more commercial friendly and internationally recognized.
  * **EUPL 1.2**, because it is especially develop for states of Europe.

## Consequences

**Good:**

* as free as possible and as legally secure as necessary

**Bad:**

* pssst, do not describe here

**Neutral:** 

* none

## Note

The decision is from project start, but documentation is now.
