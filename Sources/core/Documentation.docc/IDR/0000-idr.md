# IDR#0000 Implementation Decision Records

2026-01-01

## Context and Problem Statement
The decisions made today must still be comprehensible in the future.

## Decision

Chosen option: Use **Implementation Decision Records** (IDR) to describe decisions. Use IDR instead of ADR because not all important decisions are parts of architecture of this project. In result of implementation goes beyond administration, no template is required

## Consequences

**Good:** 

* Fast and understandable documented decisions.
* Non-architecture decisions are documented.

**Bad:**
* ADR is a well-known term instead of IDR.
* More administration is required

**Neutral:** 
  * none
