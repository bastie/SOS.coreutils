# IDR#0003 vibe programming

2026-02-01

## Context and Problem Statement
Vibe programming - the declarative programming with problem description instead solution coding - is a mainstream programming type. 

## Decision

**Chosen option:**
* Vibe programming is permitted.
* Vibe programming can be marked with the programming KI name. This programms should be hard tested and checked. The check can be do another KI.

## Consequences

**Good:** 

* It is clear what is permitted.
* The parallel using of two or three KI system to vibe programming seems create good source code.

**Bad:**

* The work context goes from implementation to problem describtion and quality check.

**Neutral:** 

* It need time to understand what vibe code do, but it need also time to do it self.
