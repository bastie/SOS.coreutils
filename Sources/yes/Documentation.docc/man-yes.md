# ``yes``

Print forever a message.

## **SYNOPSIS**

    yes [message]

## **DESCRIPTION**

The **yes** utility prints the message, or by default `y` forever on standard output.

## **EXIT STATUS**
This programm never ends.

## **EXAMPLES**

```bash
$ yes n
n
n
…
```

## **NOTE**

> Important: Unlike of other implementations, `CTRL + C` works, but slows down the output.
